#research #agenticAI 
- Zero-shot - The AI ability to recognize/classify data without prior knowledge based on basic concepts. Example: AI doesn't know "zebra" but knows "stripes" and "horse" therefore can classify zebra as a zebra without prior knowledge ^zeroshot
- Few-shot - provides input output examples within the prompt. Allows the model to learn from few examples. This helps reduce the initial dataset and improve accuracy for specific tasks. ^few-shot
- Autoregressive - machine learning technique that forecasts future values in sequence based on linear combination of previous values and is strongly influenced by it. Used for effective prediction and text generation.
- Prompt-based paradigm - LLMs are adapted to use prompts to steer the output. 

The following concepts are used for [[AI General#^zeroshot|zero-shot]]:
- Transfer learning - AI made for one task is reused as base for task that is related. ^transfer-learning
- Generalization - form of [[AI General#^transfer-learning|transfer learning]], where AI generalizes to new domain or task.  
- Auxiliary information - use semantic information to connect known to unknown concepts.

# Things to keep in mind
- Make the AI aware of the environment so it doesn't hallucinate - If the AI is prompted with "make dinner", it will start with stuff like "open fridge", "get chicken", etc., but the fridge is empty.
